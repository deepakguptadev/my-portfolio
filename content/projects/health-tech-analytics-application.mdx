## Overview

A health-tech application that improves clinical workflows, operational efficiency and data accuracy for healthcare professionals. It brings together clinical, operational, financial and behavioural data to support quality checks, patient-related evaluations and medical-record validation, helping teams capture data accurately through interactive interfaces, digital assessment tools and offline-ready workflows.

## Context

Healthcare users need structured, reliable workflows for capturing and evaluating data, often on tablets and handheld devices. The client is React and Redux; the backend is Spring Boot microservices with MySQL.

## My role

Senior Software Engineer: designing healthcare-focused UI wireframes in Figma and turning them into responsive, accessible React components; implementing interactive digital assessment screens for capturing clinical and operational data accurately and consistently; enabling QR/barcode scanning to quickly load patient records, medical assets or clinical evaluation forms; keeping the experience responsive and mobile-optimized for tablets and handheld devices; and writing unit tests for reliability and data accuracy.

## Engineering challenges

- **High data-accuracy requirements.** Clinical and operational data feeds evaluations and record validation, so capture had to be accurate and consistent.
- **Complex assessment workflows.** Digital assessments had to capture structured clinical and operational data.
- **Mobile and tablet interaction.** Healthcare workers use tablets and handheld devices, so every screen had to work there.
- **Distributed service integration.** The frontend depended on several Spring Boot microservices.
- **Consistent validation and error states.** Users needed the same, clear feedback across every assessment and record workflow.

## Decisions & tradeoffs

| Decision            | Why                               | Trade-off                    |
| ------------------- | --------------------------------- | ---------------------------- |
| React + Redux       | Reusable UI and predictable state | Workflow complexity          |
| Spring Boot         | Enterprise backend                | Distributed-service overhead |
| Microservices       | Domain separation                 | Operational complexity       |
| MySQL               | Structured data                   | Schema evolution             |
| API-driven workflow | Clear service boundary            | Network dependency           |
