## Overview

An internal platform for product quality inspection, used on iPads as an installable progressive web app. Inspectors scan a product, start an inspection session, mark defects directly on interactive product images, attach photo evidence and submit a quality result.

## Context

The application runs on iPads in an inspection environment, so it was built as a PWA with offline support, session management and inactivity detection alongside the core inspection workflow.
