## Overview

An enterprise reporting application providing data analytics, integration and visualization across complex, interconnected services. React, Power BI, .NET Core, MySQL and Azure work together to turn distributed service data into actionable business intelligence.

## Context

The application combines an enterprise frontend with backend APIs, relational data and BI reporting, so the work spans the full data flow rather than a frontend-only dashboard.

## My role

Senior Software Engineer: designing UI wireframes and translating them into production code, writing unit tests for quality and reliability, and debugging and fixing issues during development.

## Engineering challenges

- **Distributed enterprise data.** Reporting data came from many interconnected services.
- **Data-heavy visualization.** Dashboards had to present large amounts of data clearly.
- **Frontend/backend contract management.** The React frontend and the .NET Core APIs had to agree on the shape of reporting data.
- **Reporting performance.** Data-heavy views still had to load and respond quickly.
- **Debugging across application layers.** Issues could originate in the UI, the APIs, the database or the reporting layer.

## Decisions & tradeoffs

| Decision        | Why                            | Trade-off              |
| --------------- | ------------------------------ | ---------------------- |
| React / Next.js | Structured, reusable UI        | Application complexity |
| Redux           | Predictable state              | Global-state overhead  |
| .NET Core       | Enterprise backend integration | Polyglot stack         |
| MySQL           | Relational persistence         | Schema management      |
| Power BI        | Advanced BI capabilities       | Integration dependency |
