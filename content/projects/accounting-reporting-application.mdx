## Overview

A full-stack web application for non-profit organizations covering fund management, grants, donations, financial workflows, investment tracking and reporting. It integrates with CRM and financial systems, giving teams a unified, transparent view of their accounting and fund data through dashboards and automated workflows.

## Context

The platform brings complex financial and fund-related workflows together in dashboards and structured modules. The frontend had to be responsive and accessible for non-profit staff, while a Node.js backend handled application workflows and MongoDB persisted the data.

## My role

Senior Software Engineer: designing UI wireframes in Figma and converting them into responsive React and Next.js components; implementing the fund management, donor records, grant tracking and financial reporting modules; simplifying complex financial tasks for non-profit staff with accessible interfaces and workflows; and writing unit tests to keep the modules reliable.

## Engineering challenges

- **Complex financial workflows.** Funds, grants, donations, investments and reporting each needed their own structured flow in one application.
- **Client/server validation consistency.** Rules enforced in the forms had to match what the Node.js backend accepted.
- **Data modeling.** Financial and fund data had to be shaped in MongoDB for both day-to-day workflows and reporting.
- **Accessible, data-heavy interfaces.** Dense financial screens still had to be usable and accessible.
- **API error handling.** Failed requests had to surface clearly in the UI.
- **Reliable persistence and loading states.** Users needed to see when data was loading, saved or failed.

## Decisions & tradeoffs

| Decision        | Why                          | Trade-off                    |
| --------------- | ---------------------------- | ---------------------------- |
| Next.js + React | Structured full-stack web UI | Framework complexity         |
| Node.js         | JavaScript-based backend     | Runtime constraints          |
| MongoDB         | Flexible document model      | Reporting and query modeling |
| Redux           | Predictable client state     | Global-state overhead        |
| Docker          | Consistent environments      | Container overhead           |
